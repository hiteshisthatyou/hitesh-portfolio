# Hitesh Vishwakarma Portfolio

A responsive, cinematic Next.js portfolio for fintech product operations, business execution, analytics and automation.

## Features
- Responsive navigation and mobile menu
- Scroll progress and motion-based section reveals
- Career journey across PhonePe, Amazon Pay and Wint Wealth
- Selected work cards with expandable case-study views
- Impact metrics drawn from the current CV
- Filterable skills toolkit
- One-minute introduction modal
- WhatsApp, LinkedIn and email contact links
- Downloadable CV at `/HiteshVishwakarmaCV.pdf`
- SEO metadata, canonical URL, Open Graph metadata, robots and sitemap
- Reduced-motion support and mobile-specific layouts

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

## Deploy with GitHub + Vercel
1. Extract this ZIP.
2. In your GitHub repository, replace the existing project files with the contents of the `hitesh-portfolio-main` folder. Keep the folder structure intact. Do not upload the outer folder as an extra nested directory.
3. Commit the changes to the production branch connected to Vercel.
4. Wait for the Vercel deployment to show **Ready**.
5. Test the homepage, mobile navigation, case-study popups, contact links and CV download.

## Before publishing
- Confirm all metrics, dates and role titles match your final CV.
- The case-study summaries are intentionally high-level and omit confidential partner/customer information.
- The platform transaction-volume growth statement is explicitly described as platform growth, not individual attribution.
