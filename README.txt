This is the updated Next.js portfolio project.

WHAT'S INCLUDED
- Cinematic, scroll-animated portfolio with career journey and selected work
- Direct WhatsApp, LinkedIn and email links
- Download CV links in the header, hero and contact section
- Latest one-page CV at public/HiteshVishwakarmaCV.pdf
- Responsive navigation and mobile-friendly contact actions

RUN LOCALLY
1. Install Node.js (LTS).
2. In this project folder run: npm install
3. Run: npm run dev
4. Open http://localhost:3000

DEPLOY TO GITHUB + VERCEL
1. Extract this ZIP.
2. Upload the CONTENTS of the hitesh-portfolio-main folder to the root of your existing GitHub repository (not the outer folder itself).
3. Commit the changes.
4. Vercel will automatically build and deploy from GitHub.
5. Wait for the deployment status to show Ready, then test the website and the Download CV link.
